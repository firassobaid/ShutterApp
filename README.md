# 🎬 Movies App  

An Android app built with **Kotlin**, leveraging modern Android development tools and best practices. The app fetches and displays movies and genres from the IMDb API.

## 🚀 Tech Stack  
- **Kotlin**  
- **MVVM Architecture**  
- **Jetpack Compose**  
- **Kotlin Flows**  
- **Repository Pattern**  
- **Retrofit** (Networking)  
- **Coil** (Image Loading)  
- **Dagger Hilt** (Dependency Injection)  
- **Clean Code Architecture**  

## 📸 Features  
- Browse movies and genres  
- Modern UI with **Jetpack Compose**  
- Efficient API handling with **Retrofit**  
- Smooth image loading using **Coil**  
- Dependency injection with **Dagger Hilt**
